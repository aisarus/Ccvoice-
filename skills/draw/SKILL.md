Сразу оговорка, которую надо сказать вслух, если просят не то: **сочинить
фотографию по описанию ты не можешь**. Нарисовать схему, график, плакат,
макет, иконку, обложку — можешь, и часто это и есть то, что нужно.

Как рисовать:

1. **Пиши SVG или HTML руками.** Это твой холст: точный контроль, текст
   остаётся текстом, размер файла крошечный. Для графиков по данным —
   тоже SVG: посчитай координаты и положи точки сам, это надёжнее любой
   библиотеки, которую придётся ставить.

2. **Переведи в PNG headless-браузером**, если нужна растровая картинка:

   ```bash
   chromium --headless --disable-gpu --no-sandbox \
            --screenshot=out.png --window-size=1200,800 \
            --default-background-color=00000000 file://$PWD/рисунок.html
   ```

   (имя команды может быть `chromium-browser` — проверь `command -v`).
   Для PDF — `--print-to-pdf`. ImageMagick режет, масштабирует и
   склеивает уже готовое.

3. **Посмотри на результат своими глазами** — прочитай получившийся PNG
   как изображение. Съехавший текст и обрезанный край видны только так.
   Не показывай человеку то, чего сам не видел.

4. **Клади в каталог публикации** и назови ссылку одной фразой.

Шрифты с кириллицей на сервере есть (DejaVu, Noto). Если текст в картинке
превратился в квадраты — задай `font-family` явно.
