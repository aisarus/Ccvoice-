# Claude Code на сервере: во всю силу

Оболочка держит одну долгую сессию Claude Code. Всё, что он умеет, доступно
голосом — но только то, о чём он знает, что оно у него есть. Эта страница
говорит, что у него есть сейчас, чего нет и как добавить.

Английская версия этой страницы ещё не написана.

---

## Что было не так

SDK, если ему не сказать иначе, передаёт CLI **пустой системный промпт**:

    claude --system-prompt '' …

Это не мелкая настройка. Системный промпт Claude Code — то, что учит его
планировать работу, держаться соглашений проекта, проверять сделанное и
доводить задачу до конца. Без него инструменты остаются на месте, а работа
становится вялой: короткие ответы, брошенные на полпути задачи, лишние
вопросы. Снаружи это выглядит не поломкой, а «модель стала хуже».

Теперь сессия получает собственный промпт Claude Code плюс приписку о том,
где она живёт: что человек слышит одним ухом на ходу, экрана не видит и
задать уточняющий вопрос ему дорого. Приписка собирается на месте из того,
что на машине правда нашлось, — обещать несуществующий ffmpeg хуже, чем
промолчать.

---

## Что теперь умеет

**Сайты, отчёты, картинки, видео — со ссылкой.** Всё, что кладётся в
`PUBLIC_DIR`, отдаётся по `PUBLIC_URL`. `public/дом/index.html` открывается
как `<адрес>/p/дом/`. Каталог без `index.html` показывает список файлов —
с телефона это единственный способ увидеть, что там вообще накопилось.
Сессии об этом сказано, и она заканчивает работу тем, что называет ссылку
одной фразой.

**Исследование.** Поиск в интернете и чтение страниц включены. Работа,
которая разветвляется — прочитать десять источников, проверить двадцать
файлов, попробовать три подхода, — уходит субагентам, и они работают
параллельно.

**Рисовать и монтировать.** На сервере стоят ffmpeg, ImageMagick и
headless-браузер. Схема, график, плакат, макет — это SVG или HTML,
отрисованные в PNG через браузер. Видео — сборка из кадров, нарезка,
наложения, подписи через ffmpeg.

**Навыки, субагенты, память проекта.** Читается всё, что лежит на диске:
`CLAUDE.md` рабочей папки, `.claude/settings.json`, навыки из
`.claude/skills/`, субагенты из `.claude/agents/`, свои команды. Навык —
это папка с `SKILL.md`; положил её в рабочую папку, и она доступна голосом
в тот же миг, без выкладки и перезапуска.

---

## Чакры: что можно сказать

Семь навыков лежат в `workspace/.claude/skills/` и уезжают в рабочую папку
сервера при установке и при каждом обновлении. Навык — это папка с `SKILL.md`;
Claude Code подхватывает её сам, по описанию, из живой речи. Команду не надо
заучивать и не надо произносить точно: включает смысл сказанного, а не
формула.

| Скажи                                          | Что произойдёт |
| ---------------------------------------------- | -------------- |
| «что ты умеешь», «какие возможности», «чакры»   | проверит машину на месте и скажет, что есть и чего нет |
| «разберись как следует», «на полную», «глубоко» | максимальное усилие, план, субагенты, враждебная проверка себя |
| «исследуй», «собери информацию», «сравни»       | субагенты ищут параллельно, факты проверяются, отчёт публикуется |
| «сделай сайт», «страницу», «лендинг»            | вёрстка под телефон, публикация, проверка, что открылось |
| «нарисуй», «сделай схему», «построй график»     | SVG или HTML → PNG через браузер, смотрит на результат сам |
| «смонтируй», «нарежь», «склей», «сделай гифку»  | ffmpeg, сжатие под потолок публикации |
| «почини», «не работает», «разберись почему»     | воспроизвести, дойти до причины, доказать починку |

Каждый заканчивается одинаково: одна-две фразы в ухо и ссылка, если есть
что показать.

Рядом с ними едут четыре субагента (`.claude/agents/`) и три файла правил
(`.claude/rules/`), а в `.claude/settings.json` включён ultracode и часовой
кэш промпта. Полный разбор — что нашлось в документации Anthropic и что из
этого включено — в [`docs/МОНСТР.md`](МОНСТР.md).

Свои навыки кладутся туда же и работают сразу — Claude Code следит за этой
папкой и подхватывает изменения, не дожидаясь перезапуска. Имя папки
становится именем команды, поэтому только строчная латиница и дефис;
описание пиши живыми фразами по-русски, иначе навык не на что включить.

## Чего не умеет

**Сочинить фотографию или видео из описания.** Claude Code такого не
умеет — ни один ключ Anthropic этого не включает. Нужен внешний генератор.
Сессии об этом сказано прямо, чтобы она говорила «не могу» вместо того,
чтобы выдать нарисованную заглушку за фотографию.

Подключается двумя способами:

1. **Исполняемый файл `voice-imagine`** где-нибудь в `PATH`. Если он там
   есть, сессия узнаёт о нём и вызывает его сама; первым делом она
   спросит у него `--help`. Что внутри — дело хозяина: `curl` к любому
   сервису и файл на выходе.
2. **MCP-сервер** в `$MCP_CONFIG` (по умолчанию `/opt/voice-shell/mcp.json`).
   Файла нет — серверов нет; появился — подключаются на следующем
   перезапуске службы.

```json
{
  "mcpServers": {
    "картинки": {
      "command": "npx",
      "args": ["-y", "какой-нибудь-image-mcp"],
      "env": { "API_KEY": "…" }
    }
  }
}
```

Ключи — в этом файле или в `/etc/voice-shell.env`, и никогда в репозитории.

## Настройки

Всё живёт в `/etc/voice-shell.env`; после правки — `systemctl restart
voice-shell`.

| Переменная    | Что делает                                              |
| ------------- | ------------------------------------------------------- |
| `CODE_MODEL`  | модель для Claude Code; пусто — та, что у CLI по умолчанию |
| `CODE_EFFORT` | `low` \| `medium` \| `high` \| `xhigh` \| `max`          |
| `CODE_SKILLS` | `all` (по умолчанию) или список навыков через запятую    |
| `PUBLIC_DIR`  | каталог публикации                                       |
| `PUBLIC_URL`  | адрес, по которому этот каталог виден снаружи            |
| `MCP_CONFIG`  | файл с MCP-серверами                                     |

Обе половины публикации нужны разом: каталог без адреса — это каталог,
ссылку на который назвать нечем, а адрес без каталога — обещание, которое
некуда положить. Задана одна — публикация выключена целиком.

## Проверить

```
sudo bash /opt/voice-shell/scripts/doctor.sh --fast
```

Раздел «во что может Claude Code» показывает публикацию, модель, усилие,
MCP и список найденных инструментов. Это ровно то, что видит сессия, —
если чего-то нет здесь, она об этом и не узнает.

---

## Осторожно

Каталог публикации **открыт всему интернету** и ничем не защищён: адрес
угадать трудно, но это и вся защита. Секретам, ключам и личным файлам там
не место.

Файл оттуда читается в память целиком — тот же процесс в это время ведёт
разговор. Потолок 64 МБ, больше — отказ, а не падение оболочки. Видео
длиннее пары минут сессия сожмёт сама: ей об этом сказано.
