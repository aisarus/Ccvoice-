# Деплой без компьютера

Всё ниже делается с телефона, в браузере. Ничего ставить не нужно.

Почему вообще деплой, а не «запустить дома»: браузер не даёт доступ к микрофону
и распознаванию речи на `http://`. Нужен `https://`, а его проще всего получить
у хостинга. Поэтому деплой — не удобство, а условие работы микрофона.

## 1. Render (5 минут)

1. `render.com` → **Get Started** → **Sign in with GitHub**.
2. **New +** → **Blueprint**.
3. Выбери репозиторий `aisarus/Ccvoice-` и ветку `claude/voice-shell-claude-code-77wwh2`.
4. Render прочитает `render.yaml` и покажет сервис `voice-shell`. Нажми **Apply**.
5. Все поля можно оставить пустыми: доступ к Claude подключается на шаге 3, уже с телефона.
6. Дождись **Live** (первая сборка — 5–10 минут, там ставится Node и CLI Claude Code).

## 2. Токен доступа

Сервис → **Environment** → значение `VOICE_TOKEN`. Скопируй.

Это единственная защита публичного адреса: с ним можно говорить с твоим Claude
и тратить твои токены. Меняется там же — поменял значение, сервис перезапустился,
старая ссылка умерла.

## 3. Открыть на телефоне и подключить подписку

```
https://voice-shell-XXXX.onrender.com/?token=ВСТАВЬ_ТОКЕН
```

Точный адрес Render показывает вверху страницы сервиса. Открой его в **Chrome**,
разреши микрофон. Токен сохранится в браузере, из адреса он сразу уберётся.

Сверху будет блок «Claude не подключён». Дальше всё делается на телефоне:

1. **подключить подписку** → приложение запустит `claude setup-token` на сервере.
2. **открыть авторизацию ↗** → войди в свой аккаунт Claude, разреши доступ,
   скопируй код со страницы.
3. Вставь код в поле → **готово**.
4. Появится долгоживущий токен (он живёт год) и кнопка «копировать». Работает
   сразу, но контейнер эфемерный — чтобы пережило перезапуск, вставь этот токен
   в Render → **Environment** → `CLAUDE_CODE_OAUTH_TOKEN` → **Save**.

Отдельный API-ключ не нужен: используется твоя подписка Claude. Если всё-таки
хочется платить по токенам отдельно — вместо этого впиши `ANTHROPIC_API_KEY`,
приложение поймёт оба варианта.

Дальше: держишь большую кнопку, говоришь, отпускаешь. Ответ приходит голосом.

## 4. Чтобы работа не терялась

Контейнер эфемерный: перезапуск — и правки исчезли. Если хочешь, чтобы Claude
Code реально работал в репозитории, добавь в **Environment**:

| Переменная | Значение |
|---|---|
| `WORKSPACE_REPO` | `https://github.com/aisarus/Ccvoice-.git` (или другой репозиторий) |
| `GITHUB_TOKEN` | personal access token с правом `repo` — тогда Claude сможет пушить |

Токен GitHub делается с телефона: `github.com/settings/tokens` → **Generate new
token (classic)** → отметить `repo`.

## Что нужно знать заранее

- **Free-план засыпает** после 15 минут без запросов. Первый заход после сна —
  около минуты на пробуждение. Дальше быстро. Если будет мешать — платный
  Starter на Render или маленький VPS с тем же `Dockerfile`.
- **Токен подписки — это доступ ко всему твоему аккаунту Claude.** Держи его
  только в Environment хостинга, не пересылай в переписке. Если утёк — пройди
  флоу заново, старый перестанет быть нужен.
- **Claude Code работает в контейнере, а не на твоей машине.** Он видит только
  тот репозиторий, который склонирован в `WORKSPACE_REPO`.
- **Распознавание речи — браузерное.** В Chrome это значит, что аудио реплики
  уходит в сервис распознавания Google. Локальный STT появится, когда распознавание
  переедет на сторону демона (этап S1 в спеке).
- **Ambient по умолчанию выключен.** Включается кнопкой в интерфейсе; чужие
  реплики в буфер не пишутся, буфер стирается при выключении режима.

## Если что-то не так

| Симптом | Причина |
|---|---|
| «нужен токен доступа» | открыл без `?token=`, вставь токен в поле на странице |
| «нет доступа к микрофону» | адрес не `https://`, либо разрешение не выдано |
| «Claude недоступен: не подключена подписка Claude» | пройди «подключить подписку» или впиши `CLAUDE_CODE_OAUTH_TOKEN` |
| после перезапуска снова просит подписку | токен не сохранён в Environment, вставь его туда |
| «код не принят или токен не выдан» | код живёт недолго — пройди флоу заново |
| первый ответ идёт минуту | сервис просыпался после сна free-плана |
| кнопка есть, текста нет | нужен Chrome: Firefox на Android не умеет SpeechRecognition |

## Альтернативы Render

Тот же `Dockerfile` разворачивается где угодно: Koyeb (free, не засыпает),
Railway, Fly.io, любой VPS с `docker run -e CLAUDE_CODE_OAUTH_TOKEN=... -e VOICE_TOKEN=... -p 443:8787`.
Render выбран за то, что весь путь проходится с телефона и без CLI.
