# Voice Shell for Claude Code

[English](README.md) · **Русский** · [Español](README.es.md) · [中文](README.zh.md)

Голос поверх Claude Code. Телефон в кармане, гарнитура на голове, руки
свободны: говоришь — Claude работает в репозитории и отвечает в ухо. Не новый
агент, а транспорт голоса, роутинг и слой представления над уже работающей
сессией.

```
Человек
  ↕ голос
Android
  ↕ WebSocket (LAN / Tailscale)
Desktop daemon
  ↕
существующая Claude Code session
  ↕
репозиторий / shell / git / tests
```

---

## Чем это отличается от того, что уже есть

У Claude Code есть голосовой режим: зажал пробел у клавиатуры — он записал
сказанное текстом. Это диктовка: ты за машиной и смотришь в экран.

Claude Code Remote Control и мобильное приложение Cursor показывают сессию на
экране телефона. Это пульт: ты по-прежнему во что-то смотришь.

Здесь на экране нет ничего. Обращение слышит сам телефон, поэтому постоянно
открытый микрофон не означает постоянный поток аудио наружу. Сказал «Клод»,
дождался сигнала, сказал фразу — Claude работает в репозитории и пересказывает
результат в одно-три предложения. Его можно перебить посреди ответа. Ему можно
отдать задачу и уйти: фоновые задачи работают в своей копии проекта и
докладывают, когда в ухе тихо.

Плата за это — узкая область применения. Раздел [«Ограничения»](#ограничения)
стоит прочитать до установки.

## Что нужно

| | |
|---|---|
| Машина, которая не выключается | VPS или домашний компьютер. Демон гоняли на Linux — больше нигде не проверяли. |
| Доступ к Claude | Подписка Claude (Pro или Max), если запускаешь это себе, либо API-ключ Anthropic. См. [«Чем авторизоваться»](#чем-авторизоваться). |
| Телефон на Android | Приложение только под Android. Приложения для iOS нет, iOS стоит последним этапом в дорожной карте. |
| Bluetooth-гарнитура | Не обязательно, но ради этого всё и делалось. Приложение поднимает микрофон самой гарнитуры, чтобы телефон не слушал через карман. |

Есть ещё браузерный клиент — попробовать, ничего не устанавливая. Он слабее:
нет обращения и нет всегда работающего «стоп». См. [`docs/DEPLOY.ru.md`](docs/DEPLOY.ru.md).

### Чем авторизоваться

Подписка Claude (Pro или Max) годится, когда **ты** запускаешь это на **своей**
машине **для себя**. С февраля 2026 Anthropic не разрешает использовать
OAuth-доступ подписки из сторонних продуктов: поднять это сервисом и пустить
туда других людей на своей подписке нельзя. Если инстансом будет пользоваться
кто-то кроме тебя, этому инстансу нужен свой API-ключ Anthropic.

Вопрос, из-за которого это выяснялось, и написанное по нему письмо —
в [`docs/anthropic-inquiry.md`](docs/anthropic-inquiry.md).

## Установка

### Сервер

По ssh, можно с телефона:

```bash
# сначала посмотреть, ничего не меняя
curl -fsSL https://raw.githubusercontent.com/aisarus/Ccvoice-/claude/voice-shell-claude-code-77wwh2/scripts/install-server.sh | CHECK=1 bash

# потом поставить
curl -fsSL https://raw.githubusercontent.com/aisarus/Ccvoice-/claude/voice-shell-claude-code-77wwh2/scripts/install-server.sh | sudo bash
```

Скрипт ставит Node, CLI Claude Code и зависимости, прогоняет тесты, оформляет
systemd-службу с автозапуском и печатает адрес с токеном для приложения. На
тестах он останавливается: если они не прошли, служба не поднимается.

С доменом, указывающим на сервер, добавится автоматический HTTPS через Caddy:

```bash
curl -fsSL https://raw.githubusercontent.com/aisarus/Ccvoice-/claude/voice-shell-claude-code-77wwh2/scripts/install-server.sh | sudo DOMAIN=voice.example.com bash
```

Без домена порт открыт наружу и трафик идёт по http. Токен защитит от чужих,
но разговор поедет открытым текстом. Ставь домен или Tailscale и закрывай порт
фаерволом.

Дальше сервер живёт двумя командами:

```bash
sudo bash /opt/voice-shell/scripts/update-server.sh   # fetch + reset, перезапуск
sudo bash /opt/voice-shell/scripts/doctor.sh --fast   # один отчёт обо всём
```

Обновление — не `git pull`: он останавливается на разошедшихся ветках и ждёт
выбора способа слияния, а слиять здесь нечего. `update-server.sh` делает
fetch + reset, печатает, что пропадёт, и ставит метку `before-update-…`, по
которой прежнее состояние возвращается.

### Демон на своём компьютере

Облачный сервис не видит твою машину. Чтобы Claude Code работал с настоящими
проектами, демон запускается локально:

```bash
curl -fsSL https://raw.githubusercontent.com/aisarus/Ccvoice-/claude/voice-shell-claude-code-77wwh2/scripts/install-desktop.sh | bash -s -- ~/твой-проект
```

Скрипт клонирует репозиторий, ставит зависимости, прогоняет тесты, генерирует
токен и запускает демон. Снаружи дома — через Tailscale.

Если за компьютером сидит Claude Code, отдай ему
[`docs/desktop-handoff.json`](docs/desktop-handoff.json): там всё то же самое
машиночитаемо — предусловия, шаги, что проверить и что сказать тебе.

### Приложение

[Скачать APK](https://github.com/aisarus/Ccvoice-/releases/download/apk-latest/app-debug.apk)
— он пересобирается на каждом пуше в рабочую ветку. Разреши микрофон и
уведомления: без уведомлений фоновая служба работать не имеет права. Дальше
три поля, один раз: адрес, токен, стартовый язык.

> **APK в релизе подписан отладочным ключом, который лежит в этом репозитории
> вместе с паролем** — keystore `android/app/voice-shell.keystore`, пароль
> открытым текстом в `android/app/build.gradle.kts`. Так сделано нарочно:
> иначе каждая сборка CI подписывалась бы новым случайным ключом и обновление
> не вставало бы поверх предыдущего. Последствие настоящее: любой может
> собрать APK, подписанный тем же ключом, и Android примет его как обновление
> твоего. **Ставь APK только из релиза этого репозитория.** Для собственных
> сборок заводи свой ключ и в репозиторий его не клади.

## Как говорить

В два такта. Это главное:

> «Клод» · пауза · дождись сигнала · «прогони тесты»

Обращение слышит маленькая локальная модель (Vosk, ~45 МБ, скачивается при
первом запуске). Её дело — «Клод» и «стоп». Саму реплику переписывает
распознаватель телефона, он на порядок точнее, но включается не мгновенно.
Сказанное одним куском тоже работает, просто хуже: через 3,5 секунды
приложение перестаёт ждать и отправляет то, что расслышала маленькая модель.

Сигнал после «Клод» — это разрешение говорить. Не дождался сигнала — реплика
уйдёт наполовину.

| Сигнал | Что значит |
|---|---|
| короткий гудок + вибрация | микрофон открыт, говори |
| мягкий щелчок + короткая вибрация | реплика принята и ушла |
| низкий гудок | ничего не расслышал, микрофон закрылся впустую |

Обращение распознаётся с допуском в одну букву: «клот», «клад», «плод» тоже
считаются обращением. «Код», «чат», «кот», «что», «как» — не считаются
никогда: это начала команд. Обращение работает и посреди ответа — это
перебивание: Claude замолкает и слушает новую реплику.

Каждая реплика уходит в одну из трёх целей, и демон выбирает сам, если цель
не названа вслух:

| Цель | Что делает | Меняет проект |
|---|---|---|
| `код` | Claude Code в рабочем каталоге | да |
| `чат` | отдельный разговор без доступа к проекту; из инструментов только поиск и чтение страниц | нет |
| `заметка` | строка в файл-инбокс | нет |

Неоднозначное уходит в `чат` нарочно: ошибочный `чат` стоит одной фразы, а
ошибочный `код` уже что-то выполнил.

Откат, память, фоновые задачи, мост в телеграм и голосовые подтверждения
оболочка делает сама, не будя Claude. Все фразы, которые она понимает, —
[`docs/ГОЛОС.md`](docs/ГОЛОС.md).

## Что ещё можно подключить

**GitHub.** Цель `код` работает через настоящую оболочку, поэтому GitHub ей
доступен через `gh` — нужен только токен:

```bash
sudo bash /opt/voice-shell/scripts/setup-github.sh ghp_ТВОЙ_ТОКЕН "Имя" почта@example.com
```

Нужен root и уже поднятая служба: скрипт пишет в `/etc/voice-shell.env`.
Токен: [github.com/settings/tokens](https://github.com/settings/tokens) →
classic → права `repo` и `workflow`. Негодный токен скрипт отвергает сразу, а
не оставляет сюрприз на потом.

После этого голосом работает «покажи мои репозитории», «создай репозиторий
voice-notes», «посмотри пул-реквесты», «сделай коммит и запушь».

**Телеграм.** Один заранее заданный чат: файл уходит из машины голосом, но
чужой голос рядом не может сменить адресата.

```bash
sudo bash /opt/voice-shell/scripts/setup-telegram.sh
```

Скрипт спросит токен бота у @BotFather, сам узнает номер чата по первому
твоему сообщению боту и пришлёт туда проверочное.

**Голосовые подтверждения.** По умолчанию выключены: `PERMISSION_MODE=auto`,
не спрашивается ничего. `guarded` спрашивает про разрушительное, `ask` — про
всё, кроме безопасного чтения.

## Запустить локально

```bash
pip3 install -r daemon/requirements-dev.txt
cd daemon && python3 -m voice_claude --workspace ~/твой-проект
```

Клиент и WebSocket живут на одном порту (`8787` или `$PORT`), демон печатает
токен при старте. На `http://` микрофон даст только `localhost`.

Без подключённой подписки (или `ANTHROPIC_API_KEY`) цели `code` и `chat`
отвечают заглушкой — петля проходит целиком, и в ухо приходит честное «Claude
недоступен» с причиной, а не выдуманный ответ.

```bash
python3 -m pytest tests -q        # 250 passed
python3 scripts/validate_spec.py  # OK: voice-shell-for-claude-code v0.2.0 (29 top-level sections)
```

Валидатор работает без зависимостей (тогда проверяются только кросс-ссылки);
`pip install jsonschema` добавляет проверку по схеме.

## Ограничения

**Чего нет:**

- **VAD-endpointing на устройстве.** Приложение решает, что ты договорил, по
  таймеру, а не потому, что услышало паузу.
- **Voiceprint.** У классификатора говорящего есть профиль `with_voiceprint` и
  веса для него, но приложение не измеряет похожесть голоса и профиль не
  включается никогда. Роль решается по одной акустике.
- **Мультипроект.** Один рабочий каталог на демон, сменить сессию голосом
  нельзя.
- **Распознавание на своём сервере.** Распознаёт телефон, а в браузерном
  клиенте — Google. Демон аудио не видит вовсе.
- **Проактивные подсказки в ambient.** `passive` работает: буфер держит десять
  минут и отвечает на вопросы по нему. Триггеры `assist` описаны в спеке и не
  срабатывают.
- **iOS.** Нет.

**Сделано, но не откалибровано:**

- **Классификация говорящего** написана и покрыта тестами на синтетических
  профилях. На реальных записях её не калибровали, так что пороги — догадка.
  С холодного старта твоя тихая реплика скорее всего вернётся `unknown`.

**Острые углы:**

- «Откати» само по себе — команда отката. Команды оболочки ищутся в начале
  реплики, после затравок вроде «клод», «давай», «ну», так что разговор об
  откате безопасен, — но реплика, начинающаяся с «откати», делает настоящий
  `git reset --hard` до прошлой точки. Отменённый коммит остаётся в истории git.
- Фоновые задачи работают только в git-репозитории. Больше двух разом не
  запускается.
- Телеграм отказывается отправлять `.env`, ключи, keystore и всё со словами
  token, secret, password, файлы вне рабочего каталога и больше 45 МБ.
  Отказывает вслух, с причиной.
- Демон под systemd обычно работает от root. CLI отказывается запускаться от
  root с выключенными разрешениями, поэтому то же поведение даётся колбэком.
- Точка отката пишется на реплику, а не на файл: откат снимает всё, что
  изменила одна реплика.

## Ключевые решения

- **Одно физическое действие — `ACTIVATE`.** Никаких tap/double-tap/swipe-команд:
  это превращает систему в пульт от телевизора. Всё остальное — речь и контекст.
- **Кнопка гарнитуры — запасной канал.** Цель: ~90% wake word, ~9%
  автопродолжение диалога, ~1% нажатия.
- **Окно диалога 15 с.** После ответа Claude wake word не нужен.
- **Речь пользователя не переписывается**, вывод Claude — пересказывается
  в 1–3 предложения (полный output остаётся на экране).
- **Barge-in.** «Стоп» = только голос; «останови работу» = interrupt в Claude Code.
- **Маршрут по смыслу, а не по кодовым словам.** Словарь решает очевидное
  мгновенно, а на живой речи («сделай, чтобы форма не отправлялась дважды»)
  цель выбирает модель — за 2,5 секунды или не выбирает вовсе. Произнесённый
  префикс, чип и прошлая поправка её не спрашивают: это уже решение человека.
- **Одна долговечная сессия**, а не новый Claude на каждый запрос.
- **Никакого своего облака.** LAN дома, Tailscale снаружи.

## Кто говорит: мастер или собеседник

Приложение слушает и на каждом речевом сегменте решает роль, которая уходит
Claude отдельной служебной строкой перед оригинальным транскриптом:

```
[voice-shell] speaker=master (говорит мастер) confidence=0.93 device=phone_mic

Исправь ошибку и запусти тесты.
```

Громкость — **главный** сигнал, но не единственный: близкий чужой голос или
твоя тихая реплика сломали бы классификацию по одному уровню. Решение —
взвешенная логистика по относительной громкости, SNR, direct-to-reverberant
ratio, C50, ВЧ-содержанию, proximity-эффекту, опциональному локальному
voiceprint и априорам устройства/непрерывности диалога.

| Роль | Что значит | Что можно |
|---|---|---|
| `master` | близкая чистая речь владельца | всё: wake, команды, barge-in, подтверждения |
| `bystander` | чужая речь, телевизор, соседняя комната | ничего; по умолчанию не отправляется вовсе |
| `unknown` | уверенности не хватает | ничего не исполняется, один короткий переспрос |
| `self_echo` | собственный TTS в микрофоне | отбрасывается |

При низкой уверенности роль становится `unknown`, а не выдумывается.
Подтверждения (`Клод хочет удалить старую папку build. Разрешить?`) принимаются
только от `master` с confidence ≥ 0.85.

Детали — секция `speaker_identification` в спеке: признаки, веса по профилям
(`acoustic_only` / `with_voiceprint` / `narrowband`), пороги, гистерезис,
жёсткие гейты, калибровка, локальная телеметрия и критерии приёмки.

## Роутинг: chat ↔ code

Не всё сказанное — задача для репозитория. Daemon держит несколько целей и
решает, куда уходит реплика:

| Цель | Бэкенд | Меняет мир | Бюджет задержки |
|---|---|---|---|
| `code` | Claude Agent SDK, persistent session | да | 3000 мс |
| `chat` | Claude Agent SDK, из инструментов только поиск и чтение страниц | нет | 1200 мс |
| `note` | локальный inbox-файл | нет | 200 мс |

Порядок решения: явный префикс → чип в интерфейсе → прошлая поправка → sticky-цель
внутри окна диалога → классификатор → быстрая модель на незнакомых словах →
дефолт. **Дефолт всегда `chat`**: неоднозначная реплика не должна исполняться.

Поправка «не туда» пересылает прошлую реплику в другую цель и запоминает
пример: в следующий раз похожая фраза уйдёт правильно сразу.

Передача между целями («перекинь это в код», «объясни попроще») переносит с
собой прошлый вывод исходной цели. Переносить нечего — оболочка так и говорит:
«Пока нечего перекидывать».

Какие фразы понимает система — [`docs/ГОЛОС.md`](docs/ГОЛОС.md).

## Второе ухо (ambient)

Выключено по умолчанию. Три подрежима:

- `off` — микрофон открыт только после активации;
- `passive` — локальный кольцевой транскрипт на 10 минут, наружу не уходит
  ничего, пока не спросишь («что он сейчас сказал», «какую цифру он назвал»);
- `assist` — транскрипт стримится в `chat`.

Сырое аудио не хранится никогда, буфер шифруется и стирается при выходе из
режима. Чужие реплики по умолчанию в буфер не попадают. Запись речи других людей
регулируется законом и различается по юрисдикциям — поэтому это настройка с
приватным дефолтом, а не деталь реализации.

Ответ в ambient-режиме — `whisper_output`: одно предложение, максимум 12 слов,
−6 дБ, только в паузу ≥1,2 с и никогда поверх твоей речи. Вход — шёпот
(отдельный STT-профиль и профиль speaker ID), кнопка гарнитуры или текст;
wake word в ambient выключен, потому что произносить «Клод» при людях — ровно
то, чего мы избегаем.

## Definition of Done (v0.1)

Claude Code на ПК, проект открыт, телефон в кармане, гарнитура на голове — и
следующие 10 минут ты не касаешься ПК:

> «Клод, посмотри TODO и возьми следующую задачу.» → «Что именно будешь делать?»
> → «Окей, делай.» → «Как успехи?» → «Продолжай.» → «Тесты проходят?»
> → «Добей и закоммить.»

Если весь цикл проходит комфортно, не доставая телефон и не глядя на монитор —
MVP доказал идею.
