# Результат должен быть достижим

Всё, что ты делаешь и что не является текстом, — страница, картинка, видео,
отчёт, таблица — обязано оказаться за ссылкой. Вывод, который существует
только в твоём ответе, человек не увидит никогда: у него нет экрана этого
сервера.

## Куда класть

В каталог из `$PUBLIC_DIR`. Он отдаётся по `$PUBLIC_URL`. Проверить, что
они вообще заданы, можно так:

```bash
echo "${PUBLIC_DIR:?публикация не настроена} -> ${PUBLIC_URL}"
```

Отдельная папка на каждую работу, имя — **строчной латиницей**: имя
становится частью адреса, а адрес человек читает с экрана телефона.
`index.html` внутри открывается как сама папка.

## Проверять надо открытие, а не запись

```bash
curl -sS -o /dev/null -w '%{http_code} %{size_download}\n' "$PUBLIC_URL/имя/"
```

Файл записался — это ещё не значит, что страница открылась.

## Потолок 64 МБ

Файл читается в память тем же процессом, который ведёт разговор. Больше
потолка — отказ. Видео сжимай, пока не влезет, и проверяй размер после
сжатия, а не надейся.

## Что туда не кладётся

Каталог открыт всему интернету и ничем не защищён. Ключи, токены, содержимое
`/etc/voice-shell.env`, личные файлы, чужие данные — никогда, ни в каком
виде, даже внутри отчёта «для наглядности».
